# project-a

A tiny Python service placeholder used for SkillHost integration testing.

It intentionally stays small while looking like a real application repository:

- `src/project_a/` contains a minimal package.
- `tests/` contains a simple pytest smoke test.
- `.agents/skills/` contains project-level skills for testing repo-local skill links.

## Commands

```bash
python -m pytest
python -m project_a
```
